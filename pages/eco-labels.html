Pillar 02 — Eco-Labels

12 labels you can actually verify. And the ones you should question.

A credible eco-label is third-party certified against a public standard with an open registry. Below are 12 — with issuer, scope, founded year and direct verification links. Plus a filterable directory and a field guide for spotting self-declared leaf logos.

1️⃣

Check the issuer

Real label names an organization + code. “FSC Mix — FSC-C123456” is traceable. A generic green leaf with no issuer is self-declared (ISO 14021 Type II).

2️⃣

Check the scope

What does it certify — energy, forest, fishery, entire company? ENERGY STAR ≠ organic. B Corp ≠ product-level.

3️⃣

Verify in the registry

Every credible label below links to its public database. Search product, license or fishery — if absent, the claim is unsubstantiated.

Credible vs. Misleading

What makes a label trustworthy?

✓ Credible — third-party certified

  • Named issuer (e.g., Marine Stewardship Council)
  • Public standard + independent audit
  • License / code you can search (FSC-C######)
  • Multi-criteria lifecycle assessment
  • Found in official catalogue (EU Ecolabel catalogue lists 90,000+ products)

Examples: ENERGY STAR, EU Ecolabel, FSC, MSC, Fairtrade, Blue Angel, Cradle to Cradle.

✗ Misleading — self-declared

  • Generic wording: “Eco-friendly”, “Green”, “Natural” — no legal definition
  • Custom leaf/globe icon with no issuer name or code
  • No registry; only the brand website backs the claim
  • Single attribute exaggerated (“CFC-free” when CFCs banned since 1987)
  • Oxo-degradable plastic called “biodegradable” — actually fragments into microplastics

Flag these per FTC Green Guides §260.4 and EU Directive on Green Claims.

Quick test in the aisle

Turn the pack around. If you can photograph a license code and find it online in 60 seconds, it is likely credible. If you can only photograph marketing copy, question it.
